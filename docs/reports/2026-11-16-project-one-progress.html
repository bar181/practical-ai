Why it matters: "make this look better" is not a solution

An AI writes well and designs badly, because nobody told it who the page is for. The studio is that brief, written once and free to use.

  • Present a mini website, not a slide show.A page can move: a photo that pans, a chart that draws itself, steps that light up as you scroll.
  • Name the job, the reader and the shape.One sentence with those three does more than ten rounds of "try again".
  • Give your agents a way to tell a proper story.Agents write the code and the report. Voices, templates and rules make the result worth reading.
  • See your draft the way your audience will.Draft posts are shown as they will look in the feed, so you review the deliverable and not a list of text.

The library is complete: every kind of page on the plan is built.

So what. A beginner opens one file and finds a starting point for a deck, a report, a page or a post. Nothing has to be designed from a blank screen.

The build scores well. The evidence that it helps anyone does not.

So what. More features will not raise the overall score. One person presenting one real deck will.

Using the tool on itself found eight faults in its instructions. All eight are fixed.

So what. One test in a fresh chat found three times as many faults as the author did. The next project tests first and polishes second.

How this was measured

  • Counts come from the library's own index, which the build rewrites every time.
  • Every tab of the library and every worked example was opened at three screen widths in Chrome: 168 checks for script errors, sideways scrolling and accessibility.
  • The beginner prompt was run once in a fresh Claude session and passed 6 of 6 points on the skill's own test.
  • The scores are the author marking their own work against ten items.

What this does not show

  • Whether it saves anyone time. No one has timed a real job with it.
  • Whether it works in ChatGPT, Gemini or any assistant other than Claude.
  • How it behaves on a real phone, in Safari or Firefox, or with a screen reader.
  • What an independent reviewer would score it.
