What it is

An order of work that stops an AI from building the wrong thing well.

Think of it as a building site with an inspector. You agree the drawing before you pour concrete, and nobody moves to the next stage until the current one is signed off.

Nine steps take an idea to a first version someone else can try: scope, reuse check, outside help, cost, simplest design, plan and front door, review, build and test, grow. Each step has a purpose, a user story for each level, what to expect, proof it is done, a prompt to paste, and a gate: a question you answer before you go on. Step 8 hands the work to a stranger, a fresh AI session that has only your instructions, and keeps a log of every place it had to guess.

BeginnerPastes one prompt into any chatbot. A small job takes the short path (steps 1, 6 and 8 in full). Leaves with a one-page plan, a reusable prompt and a test.
AdvancedCopies one skill folder into a coding agent. Any repository. The agent makes a project folder with its own checks, and stops at each gate.
ExpertAgents work unattended: gates a script runs, fresh-session tests started by an orchestrator, a score sheet. A person reads the hand-back and decides.

For teaching there is a 30-minute training: ten slides on Artifact Studio's workshop deck, a lesson timer, and a presenter window that keeps the notes off the projector.

Finding 1

Over four audits every newcomer's score rose: the teacher's from 52 to 74, the builder's from 60 to 76, the beginner's from 64 to 72.

So what. Each audit found new faults, some of them introduced by the previous round's fixes: a heading bug in the second, and in the third a check that a finished project could never pass. Both are fixed, and a gate now fills a new project and expects every check to pass, so that class of fault cannot return unnoticed. The fourth audit confirmed the builder's path recovered; its one blocking point, a copy command, is fixed and not audited again.

How it was measured

Every test was an AI session that had only the project's own files; the rubric is the author's.

Each run logged every place it had to guess, marked blocking or minor. The logs are kept unedited in projects/agentic-process/_build/runs/. The pages were checked in Chrome at phone and laptop width with an automated accessibility scan, with scripts off, and the presenter window was driven from a second window.

What it does not show

It does not show that a person can use it, or that it works outside Claude.

Every session was Claude. Nobody has run the coach in ChatGPT, Gemini or Copilot. No learner has been timed, so every time in the project is an estimate. The rubric is the author's own. The newcomer audits were independent sessions, but they are still AI reading files, not people deciding whether to come back.

Next steps

Three things move the last measure, and only the owner can do them.

  1. Owner, before the merge: run the "Try it" prompt in ChatGPT and Gemini, and note where each stops.
  2. Owner, after the merge: turn on GitHub Pages, add topics, a description and the social picture (about 30 minutes).
  3. Owner, at the next class: teach the 30-minute training once, time each part, and ask each learner to file "I tried it".
  4. Assistant, next session: build Document to action brief with this process from step 1, and time each step.
