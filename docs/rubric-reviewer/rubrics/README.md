# Rubric library

Ready-made rubrics to paste into a chat with the [rubric reviewer](../SKILL.md). Each was written
before any work was scored against it, and each says what a reviewer needs besides the work. Copy
one, change the lines to fit your job before you produce the work, then keep it fixed for every
round.

These are drafts written by AI on 23 November 2026. Nobody has scored real work with them yet.

| Rubric | For | Lines | Gates |
| --- | --- | --- | --- |
| [Proposal or report](proposal-or-report.md) | A document a reader acts on: a proposal, a report, a briefing | 6 | 2 |
| [Recommendation](recommendation.md) | A decision brief that recommends one option | 6 | 2 |
| [AI skill or prompt](ai-skill.md) | A `SKILL.md`, a project instruction or a long prompt that others will run | 6 | 3 |
| [Blank template](rubric-template.md) | Start your own, or use the [rubric writer](../rubric-writer/SKILL.md) | | |

## How to use one

1. Pick the closest rubric and adjust it to your job **before** the work is produced or read.
2. Add a pass mark if you want one. It is your call; none is set here.
3. Paste the rubric reviewer, the rubric and the work into a fresh chat. A fresh chat has not seen
   the work being made, which is the point.
4. Score each new version against the same rubric, and paste the previous review to compare.
