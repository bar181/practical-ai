# Priorities

The tools this repository is working toward. This file is generated from what is on disk, so the
flags always match the folders.

**Built so far:** 5 draft candidates in [`drafts/`](../drafts/): Artifact studio, Voice post drafter, Short video guide, Estimator, Training explainer with avatar. Working demo: Estimator. Nothing has been promoted to `projects/` yet.

| Flag | Means |
| --- | --- |
| Published | How many levels of the tool are in `projects/` (demo, simple, working, automated) |
| Student guide | Whether a step by step explainer exists, and where |
| Plan | Whether a plan is published in `plans/` |
| Commercial | Whether a commercial-grade explainer exists |
