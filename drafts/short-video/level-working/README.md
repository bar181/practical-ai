# Level working: short video guide

The common size. What most people use day to day.

**Think of it as** a film crew that keeps its kit bag packed: the same settings, prompts and captions every time.

**Status: outline.** Written from the simple level. Not yet used by anyone.

## What this level adds

A saved prompt set for each route you use, your caption style written down once, and a voice file so every script sounds like you.

## One-time setup

1. Pick the one or two routes you will really use. Ignore the rest.
2. For each, save the prompt that worked as a template with blanks: subject, action, place, camera move, light.
3. Write your caption style once: size, colour, position, two lines at most.
4. Keep a folder of the stills and clips you are allowed to reuse.

## Each time

1. Fill in the script template. Count the words.
2. Fill the blanks in your saved prompt and render.
3. Check it against the guide's list before posting.
4. Post it yourself.

## When to move up a level

Move to the automated level when you do this most weeks and the setup above has stopped changing.
