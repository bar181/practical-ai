# Example: one topic, two styles

Synthetic example. Topic: what an AI agent is. Length: 3 minutes.

## As a lecture builder (inspired by the great professors at Harvard)

| Beat | Time | Said | Shown |
| --- | --- | --- | --- |
| Analogy | 0:00 to 0:30 | A chatbot is a brilliant intern who can only talk. An agent is that intern with a phone, a laptop and a to-do list | Large type: "An intern who can only talk" |
| Example | 0:30 to 1:15 | Watch it book a meeting: read the email, check the calendar, send the invitation | The three steps, appearing one at a time |
| Complexity | 1:15 to 2:15 | Add memory. Add a second tool. Now it can go wrong in new ways | One layer added per screen |
| Summary rule | 2:15 to 2:45 | The whole idea in five lines | Five lines of plain pseudocode |
| Last line | 2:45 to 3:00 | An agent is not smarter. It is allowed to act | That sentence, alone |

## As dry and sarcastic (inspired by Gen X humour)

| Beat | Time | Said | Shown |
| --- | --- | --- | --- |
| The hype | 0:00 to 0:30 | You have been told agents will run your whole business by Friday | Caption: "Any day now" |
| Deflate it | 0:30 to 1:15 | An agent is a chatbot that has been handed the keys. That is the entire innovation | Stock footage of someone confidently pressing the wrong button |
| Plain truth | 1:15 to 2:30 | It reads, it decides, it does one thing, it checks. Sometimes in that order | The four steps, as a slightly crooked list |
| Grudging recommendation | 2:30 to 2:50 | Fine. Give it one boring task you already understand | Caption: "One. Boring. Task." |
| Last line | 2:50 to 3:00 | If you cannot explain the job, do not delegate it. To anyone | That sentence, alone |

Same topic, same core areas, same length. A beginner class gets the first. A room that has heard
too many promises gets the second.
