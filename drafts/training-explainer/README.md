# Training explainer with avatar

Turn a topic into a taught video, in a teaching style you choose from a menu.

**Think of it as:** a cover band's set list. The song (your topic) stays the same. The arrangement
(the teaching style) changes how it lands. Pick the arrangement for the room.

**Who it is for:** instructors, course builders and anyone who explains things for a living.
