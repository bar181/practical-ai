# Level automated: weekly brief with research

**Status: outline.** The skill is written. It has not yet been run by a second agent.

## What this level adds

The `weekly-brief` skill on a schedule each Friday. The brief waits for you to read and send it.

## Install the skill

The skill is the folder [`skills/weekly-brief/`](../../../skills/weekly-brief/). In an assistant that supports skills, add the folder. In any other assistant, paste its `SKILL.md` into the instructions of a Project.
