# Commercial grade: what a commercial build adds

This folder explains. It never holds a project.

| Area | In this repository | In a commercial build |
| --- | --- | --- |
| Sources | A topic list | A managed source list with paid data feeds and a record of what was searched |
| Inside material | Files you attach | Access rules on which documents may be read, by whom |
| Review | You spot-check three links | An editor checks every claim before it goes to a wider audience |
| Record | The brief itself | An archive, searchable, with corrections noted |

## What does not change

- No invented facts.
- A person approves anything that goes out.
