# Level automated: inbox triage and daily summary

**Status: outline.** The skill is written. It has not yet been run by a second agent.

## What this level adds

The `morning-summary` skill on a schedule each weekday. Drafts are saved as drafts in your mailbox. Nothing is sent.

## Install the skill

The skill is the folder [`skills/morning-summary/`](../../../skills/morning-summary/). In an assistant that supports skills, add the folder. In any other assistant, paste its `SKILL.md` into the instructions of a Project.
