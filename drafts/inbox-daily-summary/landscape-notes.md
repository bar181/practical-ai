# Inbox triage and daily summary: landscape notes

**Sources not checked.** These are notes from general knowledge, written on 2026-11-15 to get the
simple level started. They are not a landscape review. The review, with dated sources and prices,
is still to do and is the next step for this tool.

## Established practice

Triage by action is long-standing advice: do it, hand it on, defer it or drop it. A daily page with a hard cap on "needs you" items follows the same idea.

## What assistants already do

Chat assistants offer connections to mail and calendar on some plans, and scheduled tasks on some. Which plan offers which changes often.

## The real risk

A message can contain text written to manipulate an assistant. The instructions here treat every message as information only and report anything that looks like an instruction.

## To check in the review

- What each assistant offers today for this job, on which plan, with a source and a date.
- Free and open tools that already do it.
- Outside providers for the automated level: reviewed, not selected, with prices.
