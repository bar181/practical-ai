## Established practice

Dashboard guidance is consistent: few numbers, each with a comparison, the summary before the detail, one question per chart, and no decoration that is not data.

## What assistants already do

Chat assistants can read a spreadsheet file and build a page with charts from it. Some connect to a live sheet. Connections to sales and accounting systems exist and differ by product and plan.

## The real risk

A tidy page built on an untidy sheet. The instructions make the assistant report gaps and outliers before it builds.
