# Commercial grade: what a commercial build adds

This folder explains. It never holds a project.

## What changes

| Area | In this repository | In a commercial build |
| --- | --- | --- |
| Authors | One person, one voice file | Several authors, each with an owned and versioned voice file |
| Approval | You read it and post it | An approval chain with a named approver per channel |
| Brand | Your own judgement | Compliance checks against brand and legal rules before approval |
| Record | None | An archive of what was drafted, edited and published, and by whom |
| Measurement | None | Results per post fed back into what gets drafted next |

## What does not change

- No invented facts.
- A person approves anything that goes out.

## Signs you have outgrown the levels here

- Two people posted for the same brand and it read like two companies
- Something was published that should have been checked by legal
- Nobody can find last quarter's posts
