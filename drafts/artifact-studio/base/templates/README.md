# Templates

Everything the studio can make, in one index. Open a file to see it, copy it to start from it, or give the short ask to an assistant.

This page and [`index.json`](index.json) are generated by `base/source/build.py` from the templates themselves. Edit the views or `base/source/catalog.py`, not this file.

**In the library:** 20 templates (4 pages, 7 voices, 4 decks, 5 social formats), 36 components (12 page parts, 12 photo parts, 12 animated SVG files) and 9 looks.

| Folder | What is in it |
| --- | --- |
| [`pages/`](pages/) | Whole pages: report, proposal, explainer, landing page |
| [`voices/`](voices/) | One case told seven ways, each a full page |
| [`decks/`](decks/) | Slide decks you present with the arrow keys |
| [`social/`](social/) | Post shapes you download as pictures |
| [`components/`](components/) | The parts: page parts, photo parts and animated SVG files |
| [`looks/`](looks/) | One line dressed nine ways |

Every example uses invented content. GitHub shows HTML as source, so download a file and open it in a browser.

## Photo parts

All twelve are in [`components/photo-parts.html`](components/photo-parts.html), each with the sentence that asks for it.

| Part | Use it for |
| --- | --- |
| Pan and zoom | A still photo that moves slowly reads as film. Use it to open a page or to hold a quote. |
| Parallax window | The photo moves slower than the page, so the frame feels like a window with depth behind it. |
| Photo-filled type | One word, large enough that the letters become windows. Good for a chapter break. |
| Scrolling photo tour | The photo stays put while the text scrolls. Each paragraph moves the camera to the part it talks about. |
| Self-drawing line art | A sketch that draws itself as you scroll, then gives way to the real photo. The treeline, island and trunk were traced from the photo's own pixels. |
| Chart from the photo | A chart is a component too. These numbers are measured from the photo, so the chart and the picture tell the same story. |
| Before and after | Two versions of one picture with a divider to drag. It makes a change obvious without a word of explanation. |
| Looks and voices | The same photo and the same message, five ways. A look sets the mood; a voice sets how it speaks. Describe both and a page stops sounding generic. |
| Frosted glass card | Facts float over the photo on a pane that blurs what is behind it. The photo stays the star and the text stays readable. |
| Bento grid | A summary as a tray of tiles in different sizes. Each tile holds one fact, so the eye can land anywhere. |
| Swipe gallery | Cards in a row that snap into place one at a time. On a phone it is the most natural way to browse a set. |
| Flip postcard | A photo with a second side. Put the picture on the front and the message on the back. |

## How a combination is picked

Each template carries a score from 0 to 3 for six goals and five audiences. A request is scored as three times the goal fit plus twice the audience fit, and the highest wins. The scores are in [`index.json`](index.json) and `base/source/catalog.py`, so you can read them and change them. The Pick tab of the studio page and the MCP server both use the same rules.
