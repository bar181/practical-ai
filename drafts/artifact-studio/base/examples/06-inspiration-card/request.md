# Example: keeping a design you like

A worked example: what was asked, what came with it, what the studio chose and what came back. The business and every figure are invented.

## The request

> I just saw an annual review that opened with one huge number and nothing else. Every section did the same with a smaller one. Loved it. Keep that for me.

## The notes that came with it

- It was a charity's annual review, on their website
- The first screen was one number and a few words
- Each section opened with a smaller number
- The last section had no number, just a sentence

## What the studio picked

No template was needed. This request is answered by one tool and one rule.

## How it was made

No template is involved. The assistant wrote a card from [`card-template.md`](../../inspiration/card-template.md) in its own words. It recorded the idea: the structure and the rhythm. It copied nothing: no text, no figures, no name. With the MCP server connected this is one call to `add_inspiration`.

## The output

- [`output.md`](output.md): the card, as it would be filed in `base/inspiration/inbox/`

## The note that came back with it

- **Chose:** to file a card, not to build anything.
- **Assumed:** that what you liked was the structure, not the charity's colours or wording.
- **Missing:** a link to the page. Add it to the card if you want to find it again.
- **Check before sharing:** nothing. The card is for you.

## What a good result must have

1. The card describes structure and rhythm in the assistant's own words
2. It names no organisation and copies no text, figure or picture from the original
3. It names the closest template in the library and how this differs
4. It proposes one of three outcomes: keep as a note, change a template, or build a new part
5. It has tags, so it can be found when a report is next made

## Try it yourself

Give an assistant the request and the notes above. Score what comes back against the list above, one point for each. Record the result in [`../README.md`](../README.md).
