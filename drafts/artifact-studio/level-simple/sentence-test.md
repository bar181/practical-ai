# Sentence test

Does a sentence, pasted into a fresh chat with the content, produce the page the demo shows? This
test turns "it should work" into evidence.

**Status: not yet run.** The sheet below is empty on purpose.

## How to run one test

1. Open a new chat with nothing else in it. No project instructions, no memory of earlier work.
2. Paste one sentence from [`sentences.md`](sentences.md).
3. Attach the test content for that kind of sentence.

   | Sentence kind | Attach |
   | --- | --- |
   | Photo component | One landscape photo of your own |
   | Page component | Nothing. Use the figures in the sentence's own demo, typed as three lines |
   | Voice | The fact sheet below |
   | Recipe | Notes for one real thing of your own, about half a page |

4. Open the result at phone width.
5. Score it and add one row to the sheet.

## Fact sheet for voice tests

Paste this under the sentence. It is the same invented case the demo uses.

```
A twelve-person kitchen renovation company.
Before: median first reply to an enquiry took 26 hours. 12% were answered within an hour.
Change: every enquiry now gets a drafted reply within minutes. A person reads it, fixes it, sends it.
After a 90-day trial: median reply 38 minutes. 81% answered within an hour.
Site visits booked per month rose from 18 to 31.
Staff time on replies fell from 6 hours a week to 2.5.
These figures are invented for testing.
```

## Scoring

| Score | Meaning |
| --- | --- |
| 2 | Pass. The page does what the sentence asked, works at phone width, and added no facts |
| 1 | Partial. It needed one follow-up message to get there |
| 0 | Fail. Wrong component, broken on a phone, or invented content |

A sentence is accepted when it scores 2 in both assistants. A sentence that scores 0 is rewritten
and tested again. Record the rewrite, not only the result.
