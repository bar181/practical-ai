# Style cards

Paste one card into your request, together with your design spec. A card has six fields. To add a
style, fill in the blank card at the end.

## Clean

| Field | |
| --- | --- |
| Feels like | A well-edited reference page |
| Layout | One column, generous margins, clear headings, short sections |
| Type | One typeface. Size and weight carry the hierarchy |
| Colour | Neutral background, one accent colour used sparingly |
| Motion | None, or a gentle fade on load |
| Avoid | Decoration, gradients, more than one accent, centred body text |

## Cinematic

| Field | |
| --- | --- |
| Feels like | A film title sequence |
| Layout | Full-height sections, one idea per screen, large imagery or dark colour fields |
| Type | Very large display headings, small quiet body text |
| Colour | Dark base, one strong highlight |
| Motion | Slow reveals as each section enters. Nothing that loops |
| Avoid | Dense text, small images, busy navigation, anything that moves constantly |

## Scrollytelling

| Field | |
| --- | --- |
| Feels like | A guided walk through a story or a process |
| Layout | A visual that stays in place while short text steps scroll past it and change it |
| Type | Short paragraphs, one per step, large enough to read while scrolling |
| Colour | Calm base. The highlight follows the current step |
| Motion | Tied to scrolling. The reader controls the pace |
| Avoid | More than about seven steps, steps longer than three sentences, motion that plays on its own |

## Dashboard

| Field | |
| --- | --- |
| Feels like | An instrument panel |
| Layout | The few numbers that matter at the top, supporting charts below, details last |
| Type | Tabular numbers, compact labels, units always shown |
| Colour | Neutral. Colour only for status and for separating series |
| Motion | None |
| Avoid | Decorative charts, unlabeled axes, more than one question per chart |

## Editorial

| Field | |
| --- | --- |
| Feels like | A magazine feature |
| Layout | A narrow reading column, pull quotes, the occasional wide image |
| Type | A serif for reading, a contrasting face for headings, comfortable line spacing |
| Colour | Paper-like background, dark text, one accent |
| Motion | None |
| Avoid | Sidebars, wide text columns, anything that interrupts the read |
