# Student projects

Pages built by students with the studio, shared with their permission.

There are none yet.

## To add one

1. Remove anything private: real names, companies, prices and client material. Replace them with
   generic stand-ins and say that you did.
2. Add a folder named for the page type, such as `monthly-report-example/`, holding the HTML file
   and a short `README.md`.
3. In the README, say which recipe, voice and look you used, the sentence you pasted, and what you
   had to fix by hand.
4. Open a pull request.

What you had to fix is the most useful part. It shows where the sentences and cards need work.
