# Look cards

A look is what the page wears: layout feel, type, colour and motion. Choose the look after the
recipe and the voice. Each card has six fields. To add a look, fill in the blank card at the end.

## Where the look comes from

Use the first of these that applies.

1. **The person's design spec or brand colours.** Follow it exactly.
2. **An image they supplied.** Take the palette from it with the method below.
3. **The default for the chosen voice.** See the last table in this file.

## Taking colours from a photo

1. Find the five or six colours that cover most of the picture. Ask for them by share, largest first.
2. The darkest becomes the text colour, and the background for dark bands.
3. The lightest, or a paler step of the largest colour, becomes the page background.
4. The most vivid colour that is not skin or sky becomes the accent. Use it sparingly.
5. Check text against its background: 4.5 to 1 or better. Darken or lighten until it passes.
6. Name each colour for the thing it came from (fog, pine, reed). It keeps choices honest.

A cool photo gives a calm page. A warm photo gives an emotional one. Do not fight the picture.

## Clean

| Field | |
| --- | --- |
| Feels like | A well-edited reference page |
| Layout | One column, generous margins, clear headings, short sections |
| Type | One typeface. Size and weight carry the hierarchy |
| Colour | Neutral background, one accent colour used sparingly |
| Motion | None, or a gentle fade on load |
| Avoid | Decoration, gradients, more than one accent, centred body text |

## Cinematic

| Field | |
| --- | --- |
| Feels like | A film title sequence |
| Layout | Full-height sections, one idea per screen, large imagery or dark colour fields |
| Type | Very large display headings, small quiet body text |
| Colour | Dark base, one strong highlight |
| Motion | Slow reveals as each section enters. Nothing that loops |
| Avoid | Dense text, small images, busy navigation, anything that moves constantly |

## Scrollytelling

| Field | |
| --- | --- |
| Feels like | A guided walk through a story or a process |
| Layout | A visual that stays in place while short text steps scroll past it and change it |
| Type | Short paragraphs, one per step, large enough to read while scrolling |
| Colour | Calm base. The highlight follows the current step |
| Motion | Tied to scrolling. The reader controls the pace |
| Avoid | More than about seven steps, steps longer than three sentences, motion that plays on its own |

## Dashboard

| Field | |
| --- | --- |
| Feels like | An instrument panel |
| Layout | The few numbers that matter at the top, supporting charts below, details last |
| Type | Tabular numbers, compact labels, units always shown |
| Colour | Neutral. Colour only for status and for separating series |
| Motion | None |
| Avoid | Decorative charts, unlabeled axes, more than one question per chart |

## Editorial

| Field | |
| --- | --- |
| Feels like | A magazine feature |
| Layout | A narrow reading column, pull quotes, the occasional wide image |
| Type | A serif for reading, a contrasting face for headings, comfortable line spacing |
| Colour | Paper-like background, dark text, one accent |
| Motion | None |
| Avoid | Sidebars, wide text columns, anything that interrupts the read |

## Keynote black

| Field | |
| --- | --- |
| Feels like | A product launch in a dark theatre |
| Layout | One idea per full screen, centred. Screens snap into place |
| Type | One sans serif, bold, very tight. Numbers larger than anything else |
| Colour | Black, white and two greys. At most one colour, used once |
| Motion | Words rise into place as each screen arrives |
| Avoid | Bullet lists, small charts, any second typeface |

## Paper memo

| Field | |
| --- | --- |
| Feels like | A printed decision paper on a desk |
| Layout | One page-shaped column on a grey surround. A header block, numbered paragraphs, one table |
| Type | A serif for text, a plain sans for headings and labels |
| Colour | White paper, near-black text, one dark accent for rules and headings |
| Motion | None |
| Avoid | Images, icons, coloured panels, anything that moves |

## Field guide

| Field | |
| --- | --- |
| Feels like | A workbook you write in |
| Layout | Boxed blocks on squared paper. Numbered steps with tick boxes. Tables for comparisons |
| Type | A condensed bold face for headings, a wide plain sans for text |
| Colour | Two colours: a dark one for structure and a bright one that means "act" |
| Motion | Only in response to the reader: a tick, a progress bar |
| Avoid | Soft shadows, gradients, long paragraphs |

## Faded film

| Field | |
| --- | --- |
| Feels like | A slide projector in a dark room |
| Layout | One lit rectangle at a time, a few words beneath it |
| Type | A high-contrast serif for the few large words, italic serif for captions |
| Colour | Warm near-black, cream, and the browns of an old photograph |
| Motion | Slides advance by hand. Captions fade up |
| Avoid | Crisp saturated photos, sans serif type, anything that looks new |
