# Recipe cards

A recipe is a page type: what goes on the page and in what order. Each recipe below has a finished
example in the studio (`drafts/artifact-studio/base/studio.html`, Recipes tab) and as a file of its
own in `drafts/artifact-studio/base/examples/`.

## Choosing

| If the page has to | Use | First-choice voice |
| --- | --- | --- |
| Tell someone how a period went and what happens next | One-page report | Analyst |
| Get a customer to choose an option and say yes | Proposal | Practical instructor |
| Make a process or an idea understood | Scrolling explainer | Teacher |
| Get one kind of visitor to take one action | Landing page | Storyteller |

If the content fits none of these, use the one-page report. It is the plainest and the hardest to
get wrong.

## One-page report

| Field | |
| --- | --- |
| Job | Answer "how did it go, and what happens next" near the top |
| Sections, in order | Title, period and reader. The whole period in two sentences. Four numbers, each with its change. One trend chart with a full-sentence heading. One breakdown table with the weak row marked. What changed. What happens next. |
| Parts | Big numbers, line chart, table with a bar per row, two plain lists |
| Voices that fit | Analyst, executive brief |
| Look | Quiet. One data colour, grey for comparisons |
| Needs from the content | The numbers for this period and the last, and the reader's name or role |
| Common mistakes | A heading that names a topic instead of stating a finding. More than one chart per point. Totals that do not add up. |

## Proposal

| Field | |
| --- | --- |
| Job | Turn a conversation into a decision |
| Sections, in order | Cover: the promise, who it is for, valid until. What you asked for, in the customer's words. What we propose, with one drawing or image. Three options with the suggested one marked. Schedule. Included and not included. Terms. One button. |
| Parts | Price cards, schedule chart, a drawing or photo, two lists |
| Voices that fit | Practical instructor, executive brief |
| Look | Calm, two colours, a serif for the large words |
| Needs from the content | The estimate with line prices, the customer's own words, dates, terms |
| Common mistakes | Prices that do not match the estimate. No "not included" list. More than one call to action. |

## Scrolling explainer

| Field | |
| --- | --- |
| Job | Teach a process or an idea one step at a time |
| Sections, in order | A title that names the process and one line on why it matters. A diagram or image that stays on screen. One block per stage: who does it, what happens, one fact. A closing line that adds the stages up. |
| Parts | Pinned diagram or scrolling photo tour, a line that fills, small drawn icons |
| Voices that fit | Teacher, practical instructor, keynote |
| Look | Dark with one bright colour, or black and white with one highlight |
| Needs from the content | The stages in order, who does each, and one fact per stage |
| Common mistakes | More than seven stages. Blocks longer than three sentences. Motion that plays on its own. |

## Landing page

| Field | |
| --- | --- |
| Job | Get one kind of visitor to take one action |
| Sections, in order | The promise in one line with a number in it. One button. A picture of the result. What you get, as three things. How it works, in three steps. One customer's words. The price. Three real questions. The promise and the button again. |
| Parts | Price cards, questions and answers, customer quote, one image or small animation |
| Voices that fit | Storyteller, pitch, practical instructor |
| Look | Two strong colours, and a third used only for the button |
| Needs from the content | The offer, the price, the action, and real customer words if a quote is wanted |
| Common mistakes | Two different buttons. An invented testimonial. Features listed where outcomes belong. |

## Adding a recipe

A new recipe earns a card when the same page type has been built by hand at least twice. Copy the
table above, fill in every field, and add a finished example to the demo before listing it here.
