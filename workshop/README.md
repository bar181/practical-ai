# Workshop

Everything used to build the tools. You do not need any of it to use one: for that, go to
[`projects/`](../projects/).

| Folder | What it holds |
| --- | --- |
| [`plans/`](plans/) | [Every project idea](plans/README.md), in three groups, a plan or North Star page for each, and the [plan template](plans/plans-template/PLAN-TEMPLATE.md) |
| [`drafts/`](drafts/) | Earlier drafts of nine tools, in an older folder layout |
| [`skills/`](skills/) | Skills an assistant can load to plan and build a tool, one folder each |
| [`tools/`](tools/) | Small scripts that check links, a project's layout and skills |

To start a new tool, use [Agentic Process](../projects/agentic-process/): its
[one-page method](../projects/agentic-process/base/PROCESS.md) and its builder skill. It began as
[what the first build taught us](plans/plans-template/BUILD-PROCESS.md#what-the-first-build-taught-us).

What gets built next is [the priority list](../docs/README.md#what-comes-next).
