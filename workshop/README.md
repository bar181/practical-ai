# Workshop

Everything used to build the tools. You do not need any of it to use one: for that, go to
[`projects/`](../projects/).

| Folder | What it holds |
| --- | --- |
| [`plans/`](plans/) | A plan or a North Star page for each tool, the [plan template](plans/plans-template/PLAN-TEMPLATE.md), the [nine-step build process](plans/plans-template/BUILD-PROCESS.md) and [`archive/`](plans/archive/) for what was replaced |
| [`drafts/`](drafts/) | Work in progress: Agentic Process version 2, and earlier drafts of nine tools in an older folder layout |
| [`skills/`](skills/) | Skills an assistant can load to plan and build a tool, one folder each |
| [`tools/`](tools/) | Small scripts that check links, a project's layout and skills |

To start a new tool, use [Agentic Process](drafts/agentic-process/): its
[nine-step method](drafts/agentic-process/PROCESS.md) and its builder skill. It is being rebuilt as
version 2, and it began as
[what the first build taught us](plans/plans-template/BUILD-PROCESS.md#what-the-first-build-taught-us).

What gets built next is decided in [`docs/practical-ai-priorities.md`](../docs/practical-ai-priorities.md).
