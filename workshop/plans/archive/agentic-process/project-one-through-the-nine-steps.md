# Worked example: project one, step by step

Artifact Studio was the first tool in this repository. It was built before this process was
written down, so this page shows two things for each step: what happened, and what the step
would have saved. Every figure comes from the repository's history.

| # | Step | What happened on project one | What the step would have changed |
| --- | --- | --- | --- |
| 1 | Scope | The wow, photo effects, was built as one tab among many and promoted late | Name the wow first and build it first |
| 2 | Reuse check | Done: existing design skills and libraries were reviewed before building | Nothing. This step was followed |
| 3 | Outside help | Not needed: the first version uses no paid service | Nothing |
| 4 | Cost | Zero for the beginner version: one file pasted into a chatbot | Nothing |
| 5 | Simplest design | The folder layout changed four times, and each change meant moving files and rewriting links | Fix the layout once, here |
| 6 | Plan and front door | A reviewer asked late for one download and a worked example for each voice | Plan the front door with the tool |
| 7 | Review | The author reviewed their own work for two days | A stranger, or a fresh session, on day one |
| 8 | Build and test | One fresh-session test found 6 contradictions the author had missed. Later, 13 fresh sessions in parallel each finished in 5 to 11 minutes and reported about 230 points of friction, including a server that broke when its folder was copied | Run this test as soon as the first version exists |
| 9 | Grow | Post previews, a new voice and two layout changes all went into one change request of more than 60 commits | One addition, one change request |

## The result

| Measure | Value |
| --- | --- |
| Days from first commit to a tested showcase | 3 (14 to 16 November 2026) |
| Folder layouts tried | 4 |
| Faults in the instructions found by the author alone | 2 |
| Faults found by the first fresh-session test | 6 |
| Independent runs on the last day | 13, plus 3 re-tests |

This is one project, measured by the people who built it. It is not a study.
