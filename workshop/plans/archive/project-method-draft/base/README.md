# Project method: the base

Everything the method is made of.

| File | What it is |
| --- | --- |
| [`METHOD.md`](METHOD.md) | The nine stages, what each produces and the gate that ends it |
| [`SOURCES.md`](SOURCES.md) | What was read when the method was revised, with links and dates |
| [`LESSONS.md`](LESSONS.md) | What went wrong on the first tool, and the rule each lesson became |
| [`scaffold/`](scaffold/) | The folder every new tool starts as, with a North Star page, a rubric and a progress note to fill in |
| [`new_project.py`](new_project.py) | Copies the scaffold to `workshop/drafts/<slug>/` and fills in the name |

The gate runner and the three checks live in [`workshop/tools/`](../../../tools/), because every tool in the
repository uses them.
