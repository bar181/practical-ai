## What changed

- **README:** a one-line pitch, the goal, the value and the new North Star. It opens on the
  finished decision tool: a sample to paste, how to copy the instructions, what you get, and how to
  tell it worked. Then your own question, then making your own tool on the short path, then the
  nine checks with the decision each helps you make. "Most readers can stop here" before the
  coder material.
- **Spec:** the goal, vision, user value and North Star from the owner. A rubric that matches the
  goal. Autopilot moved to its own tracker, `AUTOPILOT-PROGRESS.md`.
- **The method (steps source, PROCESS.md):** every step names the decision it helps you make and
  what it adds to the four files. The short path is the default. Step 8 now asks for a second
  run with a different input. On the short path the workflow card replaces the one-page plan.
- **The coach:** the short path comes before the nine steps and ends with the four files. Step 8
  says plainly that the person runs the test and pastes the reply back. Tests use invented or
  anonymised input; real data only when using the tool and where the workplace allows it. "Shared
  files" is defined.
- **The template and the example tool:** a setup guide with a no-setup route and steps for
  ChatGPT, Claude and Gemini. The card gained "Already exists" and "Last tested".
- **The decision tool:** one general decision rule (limits pass or fail; scores toward each goal
  over twelve months; above zero to lead; a "check first" step when risk is low or a deciding
  fact is missing) and a list of judgement calls the person checks first. The card matches it.

## What ran successfully

- Nine fresh-session runs of the decision tool, on two different decisions. The final run of each
  followed its own scores and rule, with 1 blocking point each.
- A fresh-session beginner walkthrough: it could run the finished example; its 3 blocking points
  (no setup how-to, real or invented test data, who runs the test) are fixed.
- Every check: the project's gates, its layout, the build, and every link in the repository.

## What still needs proof

  their last test, **not re-tested**.
- All runs were in Claude. **Nothing has run in ChatGPT or Gemini**, and no person has used it.
- From run 8, a judgement call the tool discloses counted as minor. Earlier runs counted it as
  blocking, so the counts are not directly comparable.
