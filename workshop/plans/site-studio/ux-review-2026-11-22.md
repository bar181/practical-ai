# Site Studio: UX review, 22 November 2026

A review of the Bradley Academy website, and what was fixed. It builds on PR #22.

**Who has and has not checked this:** an AI agent (Claude) reviewed the built site in Chrome
(Playwright) at 390 and 1280 pixels wide, with reduced motion on, with motion on, and with
JavaScript off, and ran axe-core on every page. No person has reviewed these findings yet. No
screen reader, no real phone and no Safari were used.

## What was reviewed

- The home page, all nine tool pages and every tab on them, About, the image brief and the 404 page.
- The static pages the site links to and embeds: the section library
  (`/web-sections/base/template/sections.html`), the sample sites index and its four sites, and the
  tone examples page (`/tone-studio/base/examples/index.html`).
- The React code in `projects/site-studio/base/examples/bradley-academy/app/`.

Lenses: art direction (`frontend-design`), front end and accessibility (Vercel web interface
guidelines, `accessibility-review`), UX and copy (`design-critique`, `ux-copy`), React code (Vercel
React best practices), and `modern-web-guidance` before the CSS changes.

Limits set by the owner: the home page and the main navigation are being redesigned separately, so
there only bugs, accessibility and performance were in scope. The About copy of Web Sections, Tone
Studio and Artifact Studio was not rewritten. Real user feedback so far: the tone examples that use
the cinematic effects got the best response, so the fixes lean into those.

## Fixed now, and why these first

The order is impact for effort. Findings 1 and 2 are broken pages, each fixed in a few lines.
Findings 3 to 5 lean into what users liked: the cinematic examples, shown large and one tap from the
live page. Findings 6 to 8 are small accessibility fixes.

## Left for later, and why

- **9, a pause for every reader:** needs a control on each capture and a design decision, not a
  quick fix. Reduced-motion readers are covered now.
- **10, the tone examples page:** the captures live in `projects/tone-studio/_build/img/`, which is
  not published next to the page. Doing it well means deciding where published copies live.
- **11, Web Sections swipe galleries:** the fix belongs in Web Sections' own library and its
  copyable HTML, with its own checks.
- **12 to 14:** low impact now; 13 goes away when the final pictures arrive.
- **15:** home page and navigation structure belong to the redesign being planned.

## How it was checked

- `npm run typecheck` and `npm run build`; `check_links.py` and `check_project.py` for Site Studio
  and Tone Studio.
- The site assembled as CI does (`build_site.py` plus the React build), served locally, and
  captured by a Playwright script at 390 and 1280 pixels, reduced motion on and off, and with
  script off. axe-core on every page. Before and after screenshots compared by eye.
- The Back bug, the 404 page and the stills were each tested directly in Chrome.
