# Level automated: dashboard

**Status: outline.** The skill is written. It has not yet been run by a second agent.

## What this level adds

The `dashboard-builder` skill run on a schedule, reading from the systems where the numbers start: sales, accounting and customer records. Those connections are reviewed in the plan and none is selected here.

## Install the skill

The skill is the folder [`workshop/skills/dashboard-builder/`](../../../skills/dashboard-builder/). In an assistant that supports skills, add the folder. In any other assistant, paste its `SKILL.md` into the instructions of a Project.

## What stays manual

| Step | Why |
| --- | --- |
| Sending, publishing or acting on the result | A person approves anything that goes out |
| Connecting accounts and paying for anything | Accounts and money stay with a person |
| Changing the rules | The rules are yours |
