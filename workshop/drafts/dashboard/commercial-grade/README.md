# Commercial grade: what a commercial build adds

This folder explains. It never holds a project.

| Area | In this repository | In a commercial build |
| --- | --- | --- |
| Sources | One spreadsheet | Several systems, with one agreed definition per number |
| Trust | You check tiles against the sheet | Tested calculations and a record of where each number came from |
| Access | Whoever has the page | Roles: who sees which numbers |
| Freshness | Rebuilt when asked | Updated on a schedule, with an alert when a source fails |

## What does not change

- No invented facts.
- A person approves anything that goes out.
