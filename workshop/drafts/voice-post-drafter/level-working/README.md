# Level working: voice post drafter

The common size. What most people use day to day.

**Think of it as** a ghostwriter on retainer: same person, same file, and they remember last week's notes.

**Status: outline.** Written from the simple level. Not yet used by anyone.

## What this level adds

One saved Project that holds your voice file, a card per channel and a running list of rules learned from your feedback. Every draft starts from all three.

## One-time setup

1. Create one chat Project named for yourself. Paste in the instructions from `level-simple/project-instructions.md` and attach your voice file.
2. Add a short channel card for each place you post: usual length, how you open, whether you use headings or links. Three lines each is enough.
3. Add a heading "Rules learned" at the end of the voice file. Every time the drafter turns your feedback into a rule, paste the line there.
4. Once a month, read the rules list and delete any you no longer agree with.

## Each time

1. Give a point of view and name the channel.
2. Edit the draft yourself. Say what you changed and why in one line.
3. Paste the new rule into the voice file.
4. Post it yourself.

## When to move up a level

Move to the automated level when you do this most weeks and the setup above has stopped changing.
