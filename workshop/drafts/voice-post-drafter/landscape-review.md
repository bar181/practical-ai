# Voice post drafter: landscape review

What already exists for writing in a person's own voice, and what guides say a voice document
should hold. Checked on 2026-11-15. The tool was drafted before this review. One thing in it
changed as a result.

## Summary

- **Assistants already learn a style from samples.** Claude has custom styles built from uploaded
  writing. For many people that is enough, and it should be tried first.
- **What this tool adds is the part a style setting does not keep:** rules written down after
  each edit, a list of facts the drafter may state, and a list of things never to mention.
- **Guides agree that paired examples teach a voice fastest.** The voice file had rules and
  whole posts, and no pairs. It has them now.

## Established practice

| Practice | What the sources say | Source |
| --- | --- | --- |
| Show the voice with pairs | For each trait, one sentence that is on voice beside one that is not. Several guides call this the most valuable part | [Made Good Designs](https://madegooddesigns.com/brand-voice-guide/), [Frontify](https://frontify.com/de/brand-voice/8-Elements-Your-Brand-Voice-Guidelines-Should-Include) |
| Keep a list of words to use and words to avoid | With a preferred alternative beside each word to avoid | [Averi](https://resources.averi.ai/templates/brand-voice-guide-template), [Page One Power](https://www.pageonepower.com/linkarati/brand-voice-tone-guidelines-and-examples) |
| Include real samples | Past writing that carries the voice, across the kinds of thing you write | [Word Studio](https://word.studio/how-to-write-a-brand-voice-content-style-guide), [Frontify](https://frontify.com/de/brand-voice/8-Elements-Your-Brand-Voice-Guidelines-Should-Include) |
| Give a reason with each "don't" | It tells the writer, or the assistant, the intent behind the rule | [Dotdigital](https://support.dotdigital.com/en/articles/14005232-brand-voice-best-practices-and-examples) |
| Treat it as a living document | Add examples over time | [Frontify](https://frontify.com/de/brand-voice/8-Elements-Your-Brand-Voice-Guidelines-Should-Include) |

These are vendor and trade guides, not studies. They are written for companies. This tool is for one person, so the
advice was taken where it carries over.

## How this tool follows it

| Practice | In this tool |
| --- | --- |
| Real samples | The voice file holds posts the person actually wrote |
| Words to avoid | The Rules section lists words and moves the person never uses |
| Living document | Every edit the person makes becomes a proposed new rule |
| Pairs | **Added after this review.** The voice file template has a "This is me, this is not me" section for three to five pairs |
| A reason with each "don't" | **Added after this review.** The template asks for a short reason beside each rule |

## Build or license

| Level | Lean | Why |
| --- | --- | --- |
| Simple | Try the assistant's own style setting first. Use this tool's voice file when you also need rules, facts and things never to mention | The built-in feature covers tone. It does not keep a fact list |
| Working | Reuse. A Project with the voice file attached | Nothing to build |
| Automated | Review scheduling and posting tools first. A person approves every post | Posting is the risky step |
