# Commercial grade: what a commercial build adds

This folder explains. It never holds a project.

| Area | In this repository | In a commercial build |
| --- | --- | --- |
| People | One inbox | Shared inboxes, with items routed to the right person |
| Privacy | You read your own mail | Rules on what an assistant may read, and a record of what it read |
| Safety | Instructions that distrust message text | Tested defences against manipulative messages, reviewed regularly |
| Record | None | What was flagged, what was missed, and how often the sorting was corrected |

## What does not change

- No invented facts.
- A person approves anything that goes out.
