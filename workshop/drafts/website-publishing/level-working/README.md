# Level working: publishing a website

The common size. What most people use day to day.

**Think of it as** hanging the picture in a gallery: a proper address, and you hold the key.

**Status: outline.** Written from the simple level. Not yet used by anyone.

## What this level adds

A static host with dashboard upload, so the page lives at a public address, and at your own domain if you want one.

## One-time setup

1. Choose one host from the landscape review. Read its free plan on its own site.
2. Create the account. Turn on two-step sign-in.
3. If you own a domain, connect it in the host's dashboard and wait for the certificate.
4. Write down where the project lives and how to delete it.

## Each time

1. Run the pre-publish check.
2. Open the file from a folder on your computer. If it works there, it will work on the host.
3. Upload the file or folder from the dashboard.
4. Open the address on a phone, signed out.

## When to move up a level

Move to the automated level when you do this most weeks and the setup above has stopped changing.
