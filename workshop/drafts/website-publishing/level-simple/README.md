# Level simple (beginner): share the link

The smallest version. Nothing to install and no account beyond your assistant.

1. Run [`pre-publish-check.md`](pre-publish-check.md).
2. Share the page from your assistant, to the narrowest audience that works.
3. Open the link signed out, to see what others see.
4. Note where you sent it.

The [student guide](../STUDENT-GUIDE.md) has the detail and the limits of this route.
