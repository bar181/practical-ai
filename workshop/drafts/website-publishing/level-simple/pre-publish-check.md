# Pre-publish check

Run this before a page leaves your hands. A person answers every line. An assistant can help find
problems. It cannot decide to publish.

## Nothing private

- [ ] No real names, addresses, phone numbers or emails that should not be public
- [ ] No prices, costs or terms meant for one customer only
- [ ] No client material, and nothing that belongs to someone else
- [ ] Photos carry no location data, and show nobody who has not agreed
- [ ] No keys, passwords or links to private files anywhere in the page's code

## True and finished

- [ ] Every number, name and date checked against its source
- [ ] No placeholder text, and nothing marked `[needs: ...]`
- [ ] Example content is labelled as an example
- [ ] It does not imitate another organisation's site or branding

## Works for a stranger

- [ ] Opened on a phone, read top to bottom
- [ ] Opened in a private window, signed out
- [ ] Every button and link does something
- [ ] It still works with motion turned off

## The decision

- [ ] I know who should be able to open it, and the sharing setting matches
- [ ] I know how to take it down
- [ ] I, a person, have decided to publish it
