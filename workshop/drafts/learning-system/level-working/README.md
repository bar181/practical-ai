# Level working: learning system

The common size. What most people use day to day.

**Think of it as** a notebook with an editor: someone reads it every week, ticks what held and crosses out what did not.

**Status: outline.** Written from the simple level. Not yet used by anyone.

## What this level adds

A weekly review that confirms drafts, ranks entries by how often they held, merges duplicates and retires answers that stopped working.

## One-time setup

1. Name one person who confirms entries. For a team, one per area.
2. Add a filter view to the sheet for each status: Draft, Confirmed, Retired.
3. Sort Confirmed entries by the Worked count, highest first. That is your top answers list.
4. Put a ten-minute review in the calendar, the same time every week.

## Each time

1. Confirm the drafts you trust. Add your role to "Confirmed by".
2. Retire any entry that failed twice. Do not delete it: a retired row stops the same wrong answer coming back.
3. Merge duplicates into the older entry and add the newer wording to Keywords.
4. Set "Last reviewed" on everything you looked at.

## When to move up a level

Move to the automated level when you do this most weeks and the setup above has stopped changing.
