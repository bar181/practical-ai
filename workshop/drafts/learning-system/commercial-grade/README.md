# Commercial grade: what a commercial build adds

This folder explains. It never holds a project.

## What changes

| Area | In this repository | In a commercial build |
| --- | --- | --- |
| Access | Whoever has the sheet | Access by team, with some entries visible only to some people |
| Audit | A role in a column | A record of who confirmed, changed and retired each entry, and when |
| Search | Words, then meaning | Search across several logs, with duplicates detected as they are written |
| Measurement | Two counts per row | How often a stored answer was reused, and the time it saved |
| Lifecycle | A weekly review | Review dates enforced, with owners reminded and stale entries flagged |

## What does not change

- No invented facts.
- A person approves anything that goes out.

## Signs you have outgrown the levels here

- Two teams keep separate logs with different answers to the same question
- An entry was changed and nobody knows by whom
- The log holds something that should never have been written down
