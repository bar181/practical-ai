# Level working: training explainer with avatar

The common size. What most people use day to day.

**Think of it as** a small production desk: script, pictures and voice each done properly, then assembled by hand.

**Status: outline.** Written from the simple level. Not yet used by anyone.

## What this level adds

A full script from the beat sheet, generated visuals for each beat, and your own voice, put together in an editor. You are on screen only if you choose to be.

## One-time setup

1. Fill in the brief and choose a teaching style from the canonical voice cards.
2. Decide your visual rules once: colours, one font, how text appears.
3. If you want your own cloned voice, set it up with your own recordings and keep the consent note.
4. Choose an editor you already know. The assembly is by hand at this level.

## Each time

1. Write the last line, then the beat sheet, then the script. Count the words.
2. Make one visual per beat. Reject any that needs explaining.
3. Record or generate the voice from the script.
4. Assemble, watch it against the brief, and fix the first thing that bores you.

## When to move up a level

Move to the automated level when you do this most weeks and the setup above has stopped changing.
