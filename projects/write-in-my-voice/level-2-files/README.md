# Level 2: save your voice guide

Do this once your first chat gives you a voice guide you are happy with.

1. **Fix the guide.** Correct any line that is not you, in the chat, until it reads right.
2. **Save it.** Copy the guide into a file using [`voice-guide-template.md`](voice-guide-template.md).
   Keep the heading "Voice guide" at the top: the skill looks for it.
3. **Save the instructions.** In Claude, add [`../base/SKILL.md`](../base/SKILL.md) as a skill, or put
   it and your guide in a Project. In ChatGPT or Gemini, paste both into a custom GPT or Gem.
4. **Use it.** Paste only the draft. The skill skips the samples and uses your saved guide.
5. **Keep it current.** When you correct a revision, ask it to add the correction to the guide, then
   update your saved file.
