# Level 2: the files a chatbot uses to host the game

| Folder | What it is |
| --- | --- |
| [`chat-days/`](chat-days/) | One answer file per day, for a chatbot hosting the game with [`../base/SKILL.md`](../base/SKILL.md). Generated by `_build/make_chat_days.py`. Spoilers: they list the Gems |
| [`chat-packs/`](chat-packs/) | One answer file per prompt, named by its place in the bank in base 36 (`00` to `3g`), so a chatbot can play a friend's challenge code. Generated by `_build/make_chat_days.py`. Spoilers: they list the Gems |
| [`game-review/`](game-review/) | The review skill: plays a small browser game and scores it on a 100-point rubric for fun, usability and fairness. It is the builder's mini harness: every build loop of Rare Find ends with a fresh session running it |

The game's own Level 2 (the AI checks answers and the hosts write fresh lines, on the player's own
chatbot plan, in the Claude artifact or in any chatbot with the skill) and Level 3 (the public web copy, published by GitHub Actions, and challenge links)
are inside [`../base/game.html`](../base/game.html) and `.github/workflows/rare-find-pages.yml`.
