# Images to make

None of these exist yet. Each is made for this project with an AI image tool, from the prompt
given, and its origin is recorded in `_build/img/` when it is added. The prompts name no
character, brand, artist or real person, and ask for no text: any words are added in HTML.
The game itself needs no images: it runs on shapes and colour, so it works offline.
