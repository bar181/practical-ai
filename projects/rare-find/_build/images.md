# Images

Every image here was drawn in code or captured from the real game. None was made with an AI
image tool, and none shows a character, brand, artist or real person, except the author's own photo.
The game itself needs no images: it runs on shapes and colour, so it works offline.

| File | What it is | Made by |
| --- | --- | --- |
| `img/app-icon.svg` | The app icon: a magnifying glass over a gold gem | Hand-written SVG |
| `img/btn-play-claude.svg`, `img/btn-play-web.svg` | The two play buttons at the top of the README | Hand-written SVG |
| `img/store-1-today.webp` to `img/store-4-settings.webp` | App Store style screens: a caption over a phone showing the game | `make_store_images.py`, from the built game |
| `img/how-it-plays.svg` | The animation of four answers and their points | Hand-written SVG |
| `img/creator.webp` | The author's photo, shown in settings | Supplied by the author |
| `img/explainer/*.webp` | Screens used by the explainer page | Captured from test runs of the game |

Run `python3 make_store_images.py` again whenever the game's look changes, so the README shows the
game as it is.
