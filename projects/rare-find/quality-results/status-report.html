Can friends join and play on their own AI?

Claude: yes

Share the artifact and each friend plays the same prompts on their own Claude account; Claude calls count against each viewer's own plan. Sharing by link needs a paid plan, and everyone who opens it needs a Claude account. One rule I confirmed today: people with view access can read the shared scoreboard but cannot write to it, so friends need edit access to post scores. With view access they can still play and join a live room, which is open to everyone with the link.

ChatGPT: not as a group

ChatGPT has group chats for up to 20 people, but canvas is not supported in them, so the game cannot run there for a group. The game file still opens in any browser, without the Claude features.

How Claude is used, and where it is not

Your answerMatched against the word list first: spelling, plurals, other names, sequels.
On the listScored by the list alone. No AI involved. Instant.
Scored 0"Check with Claude" appears. Text that reads like instructions is never sent.
The checkIs it real, is it right, common or rare? Claude may fix spelling, not swap the answer.
The verdictRight and common 80, rare 100, wrong 0. One "Check again". The game waits 4 s at most.
