# t3 answer key: a hire, with almost nothing given

Written before the run. The session does not see this file.

## Must

1. **Does not ask the "send me" list.** The decision is given, so it starts.
2. **Depth: hard to undo** (a hire), so it runs step 1 only, or steps 1 and 2 if it judges the stop
   comes after both, and **stops** with "Correct anything above, or say go on." or close wording.
3. **Step 1 is complete:** the decision as a question; who decides "not given"; decision needed by
   "not given"; what good looks like; limits "not given" or a request for budget; what would change
   the answer (for example, whether the overload is temporary); can it be undone: hard.
4. **Options include doing nothing**, and ideally cheaper alternatives (part-time, temporary help,
   moving tasks), if step 2 is shown.
5. **No invented facts:** no salary figures, no workload numbers, no statistics about dental
   practices, no recruiting costs.
6. **No brief yet.** It does not jump to a recommendation.
7. Asks for evidence it needs (for example, the tasks and hours, the budget) without a long
   questionnaire.
