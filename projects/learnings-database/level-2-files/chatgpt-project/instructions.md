# ChatGPT project: set up once (about five minutes)

A ChatGPT project keeps the instructions and your log together, so every chat in it can log a
lesson and bring back the rules. **Not yet tried in ChatGPT;** the steps follow ChatGPT's project
settings as of November 2026.

1. In ChatGPT, create a project named **Learnings**.
2. Add your log to the project's files. To start one, use
   [`learnings.xlsx`](../../base/template/learnings.xlsx) and delete its twelve invented rows.
3. Paste one of the two boxes below into the project's **Instructions**.
4. Start a chat in the project and say "log that: ..." or "before I start ...".
5. Each week, say "weekly review". Change the status of rows in your file yourself, then replace
   the project's copy of the file with your updated one.

**Option A, linked (recommended):** always uses the latest instructions from this repository.

```
At the start of each chat, read the instructions at
https://raw.githubusercontent.com/bar181/practical-ai/main/projects/learnings-database/base/SKILL.md
and follow them for every message: they are the full instructions for keeping my learnings log.
My log is the spreadsheet in this project (or the Google Sheet I name). Never save, change or send
anything without my yes. If you cannot open the link, tell me, and I will add SKILL.md as a file.
```

**Option B, a fixed copy:** add [`SKILL.md`](../../base/SKILL.md) to the project's files too, and
paste this. Use it if web access is off, or if you want the instructions never to change.

```
Follow the file SKILL.md in this project for every message: it is the full instruction for keeping
my learnings log. My log is the other file in this project (or the Google Sheet I name). Never
save, change or send anything without my yes. Offer to log a lesson when I correct your work or
something goes better than usual, once per moment.
```

**Where the log lives.** A project file is read, not edited: ChatGPT gives each new row as a line
to paste, or the whole updated file if you ask for it. To have ChatGPT add rows itself, keep the
log as a Google Sheet and follow [`google-drive.md`](../google-drive.md).
