# Level 2: save it once

Level 1 is a link in each chat. Level 2 saves the instructions where you work, so every chat can
log a lesson and bring back the rules. Worth it once you log more than once a week. Pick one.

**Think of it as** pinning the instructions to the wall instead of handing them out each time.

## Claude: the plugin

A plugin is a skill plus ready-made commands, packed together.
[`claude-plugin/learnings-database/`](claude-plugin/learnings-database/) holds the skill and three
commands: `/log`, `/before-i-start` and `/weekly-review`.

- **Claude Code:** start Claude Code with `claude --plugin-dir` followed by the full path to the
  `claude-plugin/learnings-database` folder on your computer, or add it to a plugin marketplace
  you already use.
- **Claude app:** open `claude-plugin/learnings-database/skills/`, zip the `learnings-database`
  folder you find there, and upload the zip in the skills section of Claude's settings. The app
  gets the skill; the three commands are for Claude Code.

## ChatGPT: the skill

ChatGPT skills use the same open format. Zip the same `learnings-database` folder, then in ChatGPT
open **Skills**, choose **Create**, then **Upload from your computer**. Skills are on some ChatGPT
plans only. Not yet tried.

In a folder it can write to, it adds rows to `learnings.csv` after your yes. Otherwise it gives you
the line to paste.

## A Claude Project or ChatGPT project

1. Create a Project named **Learnings** and add your log as a project file. No log yet? Start from
   [`learnings.xlsx`](../base/template/learnings.xlsx) and delete its invented rows.
2. Paste this into the project's instructions:

   ```
   At the start of each chat, read the instructions at
   https://raw.githubusercontent.com/bar181/practical-ai/main/projects/learnings-database/base/SKILL.md
   and follow them for every message. My log is the spreadsheet in this project. Never save, change
   or send anything without my yes. If you cannot open the link, tell me, and I will add SKILL.md
   as a project file instead.
   ```

3. Start a chat in the project and say "log that: ...". A project file cannot be edited by the
   chatbot, so paste each new row into your spreadsheet, or ask for the updated file, and replace
   the Project's copy after each weekly review, so the chatbot reads your latest rules.

## An agent with a folder

Give the [idea file](gist/learnings-log.md) to Claude Code, Codex or Claude in a desktop folder,
and say "set this up for me". It creates `learnings/learnings.csv`, adds the instructions to the
folder's `AGENTS.md` or `CLAUDE.md`, and logs your first lesson with you.
