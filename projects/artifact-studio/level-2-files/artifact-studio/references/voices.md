# Voice cards

A voice decides what is said, in what order, and how the page behaves. It is more than tone. The
same facts told in two voices produce two different pages. Each voice has a full example in the
studio: one tab for each voice in `showcase.html`.

These cards say how each voice looks and behaves on a page. How to write in each voice, with the
story orders and formats such as an investor deck or an executive one-pager, is in Tone Studio:
https://github.com/bar181/practical-ai/tree/main/projects/tone-studio. When the two disagree on
the words, Tone Studio wins; on the page, these cards win.

Each voice is inspired by a well-known way of communicating. That is a description of a style.
Never write as if a person said it, and never put a person's name on a page.

## Keynote

| Field | |
| --- | --- |
| Inspired by | The product launches of visionary tech CEOs |
| Order | The world as it is, as one line or one painful number. The catch or the consequence. The idea in a few words. Proof as enormous numbers, or as bars with no axes. The next step. A closing line short enough to repeat. |
| Sentences | Very short. One idea each. Present tense. |
| Page behaviour | One idea per screen. Screens snap into place. Words arrive in order. |
| Look | Black background, one typeface, white and grey. Numbers enormous. A picture fills the screen with a few words over it, or sits beside one short paragraph. |
| Avoid | Bullet lists, charts with axes, more than about twelve words on a screen |

## Storyteller

| Field | |
| --- | --- |
| Inspired by | Donald Miller's story framework |
| Order | A hook: one moment with a time and a place. A character who wants something. The problem at three depths: on the surface, underneath, why it is wrong. A guide with empathy, then proof. A plan in three steps. One call to action. The stakes: failure beside success. An ending that returns to the opening. |
| Sentences | Concrete and visual. Past tense for the story, present for the offer. |
| Page behaviour | One reading column. Photographs push in slowly. One pull quote per screen at most. |
| Look | Colours taken from the photograph. Large serif type. Each story beat named in small type. |
| Avoid | The company appearing before the fourth beat. An invented customer presented as real. |

## Personal story

| Field | |
| --- | --- |
| Inspired by | The classic advertising pitch that sells a feeling through one personal story |
| Order | One memory in the first person. Two or three keepsakes. The feeling inside them, named in one sentence. What has changed and what has not. What to do. The offer, named once, at the end. |
| Sentences | First person. Short. Never more than two on a screen. |
| Page behaviour | Everything arrives slowly. One photograph fills the screen and moves. Nothing bounces. |
| Look | A dark, warm room. Serif type. Photographs faded and warm, a little crooked, with a paper border. |
| Avoid | Feature lists, numbers, charts, the product name before the end. An invented memory: ask the person for a true one. |

## Teacher

| Field | |
| --- | --- |
| Inspired by | The great professors at Harvard |
| Order | One question. An everyday analogy in very large type. One worked example with real values. The same idea as pseudocode or a diagram, stepped through. A harder case handled by what is already on the board. Questions to check understanding. A recap that reuses the analogy. |
| Sentences | Plain, second person, one new term at a time |
| Page behaviour | The reader does something: steps through, then answers |
| Look | Black and white with one highlight that means "look here". Monospace for code. Every section tagged with what kind of thing it is. |
| Avoid | Two new ideas in one step. An analogy that is dropped after the opening. |

## Practical instructor

| Field | |
| --- | --- |
| Inspired by | A best guess at Bradley Ross's teaching style |
| Order | The core idea in one sentence. One boxed analogy. Three numbers on why it matters. Numbered steps with a time on each. The same job at three levels. Common mistakes. One next step. |
| Sentences | Start with a verb. No sentence that does not help someone act. |
| Page behaviour | Everything the reader does is a control they can touch: tick boxes, a progress bar |
| Look | A field guide or workbook. Two colours: one for structure, one that means "act". Tables for comparing levels. |
| Avoid | Theory before the first step. Steps without a time estimate. |

## Analyst

| Field | |
| --- | --- |
| Inspired by | Barbara Minto's pyramid principle |
| Order | A title that is the conclusion. The answer in two sentences. Three numbers. Up to three findings, each with its own full-sentence heading, its own chart and its own "so what". Show only the findings the content holds. A finding with two or more values to compare gets a chart; one with nothing to compare has no chart and is still a finding. How it was measured. What it does not show. Next steps with owner and date. |
| Sentences | Declarative. A number in most of them. |
| Page behaviour | Charts can be touched to read values. Nothing else moves. |
| Look | Quiet. One data colour, grey for comparison. Sources under each chart. One picture at most, at the top. |
| Avoid | Headings that name a topic. Hiding the limits. Decoration that is not data. |

## Executive brief

| Field | |
| --- | --- |
| Inspired by | The board or cabinet decision memo |
| Order | Header: to, from, date, decision needed by. The decision. Background in numbered paragraphs. Options in one table, including "do nothing". Recommendation in two sentences. Risks, each with its control. Next steps. |
| Sentences | Formal and complete. No adjectives that are not facts. |
| Page behaviour | None. It is a document. |
| Look | A paper page, one column, serif type, one accent colour for rules and headings. No photographs. A table or one small chart is allowed. |
| Avoid | Images, animation, more than one page |
