# Recorded runs

Every run here was a fresh AI session given one prompt. Each folder keeps what it was given, what
it returned and what got in its way. They are evidence, so they are kept as they were made, even
where file names differ.

| Folder | What it is | Feeds |
| --- | --- | --- |
| `report/`, `photo-effects/`, `voice-*` (seven) | One prompt each (`prompt.txt`), the finished page (`out.html`) and notes. `build.py` turns each into a worked example in `../../../base/examples/` | The nine worked examples |
| `2026-11-17-try-it-keynote-photo/`, `-no-photo/`, `-try-it-now-prompt/` | The README's try-it prompt, run as a new user would: message, reply, page and setup | The README's example capture and the Pages copy |
| `2026-11-16-starter-run/` | The first end-to-end run of the skill, with its friction log | The fixes recorded in `../../../quality-results/README.md` |
| `skill-run/`, `link-run/`, `mcp-run/` | The skill loaded, the instructions by link, and the MCP server, each with friction notes | The three ways in, in `AGENTS.md` |
| `retests/round-2/` to `round-4/` | Three rounds of the deck, report and social picture prompts after fixes. The prompts are the same in each round; the notes say what changed | The evidence table in the quality results |

The post preview run moved to Web Sections with the post previews, on 21 November 2026.
