Twelve animated SVG parts

Small moving pictures, each a single file with no script. Drop one into a page, a slide or a post. Each stops moving for people who have asked for less motion, and each still makes sense when it is still.

    @@svgset

Behind these parts

Each file is plain SVG with its animation written in CSS inside the file. That means it plays as an image, inside a page, or pasted into a slide tool that accepts SVG. Colours come from four variables with built-in fallbacks, so a page can recolour a part by setting them.

How to use one

  1. As an image: <img src="line-draw.svg" alt="...">
  2. Inline: paste the file's contents into the page. Its styles are scoped to its own id, so parts do not clash
  3. To recolour inline, set --ink, --accent, --soft or --sand on the page
  4. To change a number, edit the text and the one value the description names
  5. Where SVG is not accepted, such as email, use the GIF copy in components/gif/

Design rules

  • The resting picture is the finished picture. Motion only brings it in
  • One movement per part, under three seconds, or a slow loop
  • No script and no outside files
  • A title and a description inside every file, for screen readers and for agents
  • Motion stops under "reduce motion"
