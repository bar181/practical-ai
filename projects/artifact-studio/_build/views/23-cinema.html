Effects from the Bradley Academy website

Make the page feel like a film

Eight effects that make a page feel directed rather than assembled. The website uses them with two libraries; here each one is rebuilt in plain CSS and a few lines of script, so it works in a single file you can paste anywhere.

Each effect shows its finished state if scripts are off or if you have asked your device for less motion. Use one or two per page. A page with all eight is a showreel, not a story.

1. The opening

Bars part, the title rises, the film starts

Two dark bars at the top and bottom slide away, each word of the title rises out of a mask, and a faint grain flickers for a few seconds and then stops. Scroll back to the top of this tab to see it again after a reload. Screen readers hear the whole title once.

Show the finished title if motion is reduced. || A few minutes || CSS keyframes and one class added on open || A moving image behind the title || Launches, keynotes, a personal story

2. The grade

One colour grade makes ten photos look like one film

A grade is a filter plus a warm, dark edge. Put the same grade on every photo and stock pictures, phone snaps and placeholders all sit in the same world. Turn it on and off to compare.

@@ask Give every photo the same film grade: less saturation, a little more contrast, a touch of sepia, and a dark warm edge in the page's accent colour, so all the pictures look like one film. || Under a minute || A CSS filter and one overlay || A switch to compare with and without || Any page with mixed photos

5. The stack

Each scene slides over the last

Full-screen scenes stack like cards. As the next one arrives, the one underneath shrinks a little and darkens, so the eye goes to the new one. Good for four to six things, never more.

What is not here, and why

Smooth scrolling, where the page glides after you stop, needs a library. The website uses one; a single file should not. If you want it, build a site with Site Studio, where the same effects run on GSAP and Lenis.
