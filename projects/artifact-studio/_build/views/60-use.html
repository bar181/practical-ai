How to use the studio

The studio is a menu. You point at what you want and the assistant builds it from your own content. Everything you need is in the base: this page, the template library with every template as a file of its own, the cards, the forms and the skill. A level only adds to the base.

For people: six steps

  1. Once: open the Skill tab, copy "AI instructions" and paste it into your assistant's Project instructions.
  2. Open a template you like and copy the sentence under it. Not sure which? The Pick tab suggests one. It covers pages, slide decks and social posts.
  3. Paste it into the assistant and attach your notes. Add a photo if the page should use one.
  4. Read what comes back on your phone first. Most people will see it there.
  5. Ask for changes by naming parts: "make the big numbers a ring", "use the teacher voice for the opening".
  6. Check every number and name against your notes before you share it.

For agents: the skill

The repository holds a skill called artifact-studio. It turns any content into a page by following the same menu, in this order: intake, recipe, voice, look, outline, parts, build, check.

  • It invents no facts. A gap in the content is marked on the page and listed for the person.
  • It uses real customer words for quotes, or leaves the quote out.
  • It builds one self-contained file that works on a phone and with motion turned off.
  • It reads a preferences file first, if there is one.
  • It runs the pre-ship checklist and reports the result.
  • Anything that posts, sends or publishes waits for a person.
