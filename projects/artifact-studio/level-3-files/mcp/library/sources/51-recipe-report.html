Behind this page

A one-page report answers "how did it go and what happens next" before the reader has to scroll far. This one uses the analyst voice with a quiet look.

Recipe: the order of the page

  1. Title, period and who it is for
  2. The whole month in two sentences
  3. Four numbers, each with its change
  4. One trend chart with a sentence for a heading
  5. One breakdown table, with the weak row marked
  6. What changed
  7. What happens next

Components used

  • Big numbers that count up
  • A line chart you can touch
  • A table with a small bar in each row
  • Two plain lists

Goes well with

  • Voices: the analyst, the executive brief
  • Looks: quiet, one data colour
