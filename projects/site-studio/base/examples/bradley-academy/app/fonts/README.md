# AISP fonts (generated)

Generated by `scripts/make_aisp_fonts.py`. Do not edit. Each file holds only the characters in
`app/content/aisp.ts`, so the AISP panels draw the same everywhere.

- `aisp-mono.woff2`: a subset of DejaVu Sans Mono (Bitstream Vera licence, with DejaVu changes in
  the public domain).
- `aisp-math.woff2`: a subset of Noto Sans Math (SIL Open Font License 1.1), from
  `@fontsource/noto-sans-math`.
