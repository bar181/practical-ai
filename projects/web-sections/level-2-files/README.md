# Level 2: your own section set

1. **Build one page you like** with the skill, then keep it.
2. **Write a "Section set" file** from [`section-set-template.md`](section-set-template.md): your page
   types, sections in order, hero choice and colour tokens.
3. **Save the instructions with it,** in the chatbot you use:
   - **Claude:** create a Project, paste [`../base/SKILL.md`](../base/SKILL.md) into its instructions,
     and add your section set to its files.
   - **ChatGPT:** create a custom GPT, paste the skill into its instructions, and upload your tone
     file.
   - **Gemini:** create a Gem, paste the skill and your section set into its instructions.
4. **Use it.** Describe the page; the skill uses your set in place of the defaults.
