Behind this page

Every draft here is an example about this repository, written from Bradley Ross's own teaching phrases. None has been posted. The frames are plain on purpose: they copy the shape of a feed, not any platform's logo or interface, and they show no likes or follower counts, because those would be invented.

How it is built

  1. The use case in one line, then three short reasons
  2. Three drafts of one post, side by side, with a way to choose
  3. The same message on two platforms, to show what changes
  4. One example of each remaining format
  5. The sentence that asks for each

Design rules

  • Show the draft at the width and shape its audience will see
  • Cut long text where a feed would, and let the reviewer open it
  • Put the words on the picture only when they read at thumbnail size
  • Never show invented likes, comments or followers
  • Name the platform above the frame. Do not draw its logo
  • Stop at the preview. A person presses post
