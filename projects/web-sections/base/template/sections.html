The section library

Responsive sections to start a website or page from. Each one says when to use it. Copy the ones you need, in order, then change the colours in one place. All words and pictures here are invented placeholders.

Page assemblies

The sections above, in the order that works for three common pages. Start here, then add or remove one section at a time.

  • Small business home page

    Site header, hero (photo or split), about, gallery, contact with hours, footer.

  • Landing page for one offer

    Site header, hero (centred or split), features, steps, quote if real, pricing, questions, call to action, footer.

  • Content site page

    Site header, hero (type), article with related posts, call to action, footer.

  • Portfolio

    Site header, hero (mosaic), gallery grid, about, contact, footer.

  • Event

    Site header, hero (video or photo), steps as the programme, pricing as tickets, questions, contact, footer.

  • Social post formats

    Seven picture sizes for posts, stories and link previews, in the social folder.
