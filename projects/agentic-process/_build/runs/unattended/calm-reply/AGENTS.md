# Calm Reply: instructions for agents

You are here because a person wants one long, upset customer email turned into a short, calm
reply draft that the shop owner edits and sends. People start at the [README](README.md).

## The path

| You can | Do this |
| --- | --- |
| Read one file | Read [`base/AI-INSTRUCTIONS.md`](base/AI-INSTRUCTIONS.md) and follow it |

## Output contract

Return the result, then a note with four headings: Chose. Assumed. Missing. Check before sharing.
The exact shape is in step 5 of `base/AI-INSTRUCTIONS.md`.

## Rules that never bend

1. No invented facts. A gap that would mislead the reader is marked `[needs: ...]`.
2. Stop before anything is posted, sent, paid or published. A person decides.
