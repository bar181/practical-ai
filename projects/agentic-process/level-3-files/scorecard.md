# Score sheet

Score the tool before you share it and again after every round of fixes. Score your own work
honestly: the point is to see where to spend the next hour.

| Measure | What 80 looks like | Score | Evidence |
| --- | --- | --- | --- |
| The front door | A stranger knows what it is and what to try within one screen | | |
| The beginner version | It works from one file, with nothing installed | | |
| Worked examples | One for each variant, each made from its prompt by a fresh session | | |
| The instructions | Fresh sessions finish the job with no blocking friction | | |
| Other assistants | Tried in at least two assistants that are not the one it was built with | | |
| The advanced files | A second agent has used the skill or the server end to end | | |
| Honesty | Every status line says who has tried the thing | | |
| Devices and access | Checked in two browser engines and by keyboard, with an automated accessibility scan | | |
| A clean folder | A newcomer can tell what each top-level folder is for | | |
| Real use | Three people outside the author have used it for real work | | |

Rules for scoring:

- A score needs evidence you can point to: a file, a log, a name and a date.
- If you cannot test something, the score stays low and you say why. Do not redefine the measure.
- An AI session testing the tool is a test. It is not real use.
