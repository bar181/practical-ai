# For agents: building a tool with Agentic Process

You were asked to turn a job someone repeats into a tool. Follow the builder skill:
[`level-2-files/agentic-process/SKILL.md`](level-2-files/agentic-process/SKILL.md). The method behind
it is [`base/PROCESS.md`](base/PROCESS.md); start every tool from [`base/template/`](base/template/).

- Write the five-line usable-result spec (U1 to U5) before building anything.
- Reuse first: if something existing does the whole job, ship a quick-start README and stop.
- Test in a separate session that has only the README and what it says to paste. If you cannot
  start one, write "not yet run" and put the exact test messages in the hand-back.
- Never write a result yourself and present it as a test result.
- Hand back; do not merge, publish or send anything.

What earlier runs taught the builder is in [`quality-results/README.md`](quality-results/README.md).
