## Seven tones, one story

One invented source, [`source-content.md`](source-content.md): an online course called
"Spreadsheets Without Fear". The same facts, written in each of the seven tones as a cinematic
landing page and a social post. Compare them to see that a tone is the order and rhythm of what is
said, not only the words. Each folder also has a facts check (`notes.md`).
