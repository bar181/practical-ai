# Rubric template

Copy this, fill it in before the work is read, and keep it fixed for every round.

```
Rubric: <what the work is>
Written: <date>, before the work was read (or: after the work was shared)
For: <who reads it and what they do next>
Pass mark: <number, or "none set">

| Line | Weight | Full marks looks like | Evidence to look for |
| --- | --- | --- | --- |
| <the job the work exists for> | <largest> | <one checkable sentence> | <where it would be> |
| <the usual mistake> | | | |
| | | | |
| | | | |

Weights add up to 100.

Gates (pass or fail, no points):
- <a rule with no "how good", for example "under 300 words">

A reviewer also needs: <anything beyond the work, or "nothing">
```

Four to seven lines. One thing per line. A line with a weight is always scored; a pure yes or no
rule belongs under gates. No vague words such as "high quality" or "engaging":
write what a reader would see instead.
