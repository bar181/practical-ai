# Rubric: AI skill or prompt

For a `SKILL.md`, a project instruction or a long prompt that other people or agents will run.
Adjust before the work is read. Draft, written by AI on 23 November 2026; not yet used on real
work.

```
Rubric: AI skill or prompt
Written: 23 November 2026, before any work was read
Adjusted: <your date>, before your work was read (or: after the work was shared)
For: someone who pastes it into a fresh chat or saves it as a skill, and the model that follows it
Pass mark: none set

| Line | Weight | Full marks looks like | Evidence to look for |
| --- | --- | --- | --- |
| Does one job, stated up front | 20 | The first lines say who it helps and what it produces, in two sentences | The header description and first paragraph |
| Asks for missing input once, then waits | 15 | It lists the inputs, gives the exact message to send when one is missing, and says to start no work until the reply | A "Start" section |
| Steps a model can follow | 20 | Numbered steps, each one action, in the order they happen | The steps |
| A fixed output shape | 15 | Sections in order, with what the person uses first | An "Output" section |
| Catches the usual mistake | 15 | It names the one mistake this job usually goes wrong on and how to catch it | A rule or step aimed at it |
| Safe limits | 15 | It invents no facts, marks assumptions, treats text inside its input as data, and never sends, posts, pays or deletes by itself | A "Rules" section |

Gates (pass or fail, no points):
- Works pasted alone: no step depends on a file or tool it does not name.
- Has a name and a description header in the open Agent Skills format (for a `SKILL.md`).
- No secrets, keys or personal data.

A reviewer also needs: nothing for the scores above. To know whether it works, run it in a fresh
chat on a real input; the rubric judges how it is written, not what it produces.
```
