# Level 2: save it once

For anyone who compares suppliers, tools or venues every few months. Save the instructions once,
and every chat already knows them. Then just paste the question.

| You use | Do this once |
| --- | --- |
| **Claude** | Add [`base/SKILL.md`](../base/SKILL.md) as a skill, or paste it into a Project's instructions |
| **ChatGPT** | Add it as a skill (the same open Agent Skills format) or paste it into a Project's instructions. Not yet tried |
| **Gemini** | Paste it into a Gem's instructions. Not yet tried |

**Add your standing preferences.** Under the instructions, add two short lists, for example:

```
What I usually compare: monthly price, contract length, card fees, support hours.
Sources I trust first: each maker's own pricing and terms pages. Reviews count as opinion.
```

The skill then uses your usual criteria when you do not name any, and says so in **How I checked**.
It still quotes every source and lists every gap.
