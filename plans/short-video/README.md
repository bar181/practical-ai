# Short video guide

Choose the route by length and purpose, then follow the steps for that route.

**Think of it as:** Getting across a city. A scooter, a bus and a taxi all work, but each suits a different trip.

## What it includes

- Route A: a generated clip of a few seconds for a hook or cutaway.
- Route B: a free explainer generated from your own documents.
- Route C: a short with your own avatar and voice.
- Route D: motion graphics built from code for exact, repeatable layouts.
- A four-beat script format: hook, point, proof, ask.
