# Learning system

A log of questions and the solutions that worked, so the same problem is never solved twice.

**Think of it as:** A workshop notebook where every fix is written down once, with a note on whether it held. The next person with the same problem starts from the answer.

## What it includes

- Each entry holds a question, the recommended solution, the context and whether it worked.
- Three versions: for developers (errors and their fixes), for businesses (customer and process questions with approved answers) and for personal use.
- Look up before solving. Record after solving. A person confirms an entry before it counts as recommended.
- Simple level: a spreadsheet such as Google Sheets, connected to your assistant.
- Advanced level: a vector database, for example Supabase, so entries are found by meaning and not only by matching words.
