# Course operations

A training website and the agents that handle the routine work of running a course.

**Think of it as:** A teaching assistant and a program coordinator who never forget a reminder, and who hand anything unusual to the instructor.

## What it includes

- Training website: lessons, schedule and resources in one place, with the assistant built in.
- Program manager: schedules, reminders, surveys and a summary of the results.
- Student assistant: answers from the lesson material and names the lesson it used.
- Works alongside a learning platform you already use, or as a simple hosted site.

## Priority list entries this plan covers

- Training website
- Student AI assistant
- Course program manager
