# Plans index

One folder per planned tool. Each README gives an overview, what might be involved at each level,
and a complexity flag. A plan is a starting point: it is updated as research is done and replaced by
a draft and then a project as work proceeds.

How a plan becomes a tool is the [project method](../drafts/project-method/): seven stages, a gate after each.
Plans written before 15 November 2026 describe four sizes of each tool (demo, simple, working, automated).
The current layout is a base and up to three levels that hold only what they add. [`archive/`](archive/) says what changed.

To add or update a plan, use [`plans-template/`](plans-template/). It holds the nine-step build
process, the template and the instructions. The skills that do the work for you are in
[`../skills/`](../skills/).

## Complexity scale

| Complexity | Means |
| --- | --- |
| Beginner | No code. A chat assistant and a few files. Usually under an hour to set up |
| Intermediate | Connecting accounts or tools, some setup and testing. A few hours |
| Advanced | Code, hosting, a database or scheduled automation. Needs someone technical |

A tool can start at Beginner and reach Advanced at its automated level. The index shows the range.

## Additional options, no plan yet

- **Course program manager:** Schedules, reminders and surveys for a cohort, with a summary of the results.
- **Daily topic scout:** A morning list of topics with draft posts, ready for review.
- **Call agent:** A voice agent that answers common questions and books appointments. Inbound first.
- **Outreach agent:** Follow-up sequences drafted in your voice and sent only on approval.
- **Sales department blueprint:** A map of sales and marketing roles to agents, assembled from the tools above.
- **Song and jingle add-on:** A short generated track for a video or page.
- **Invoice chaser:** Reminder messages for overdue invoices, matched in tone to each customer and sent only on approval.
- **Review responder:** A reply to every public review, in your voice, for approval.
- **Meeting prep brief:** A one-page brief before each meeting: who is attending, the history and the open items.
- **Procedure writer:** A recorded walkthrough becomes a step by step procedure.
- **Contract red flags:** A contract becomes a plain-language list of terms worth a second look.
- **Hiring kit:** A role brief becomes a job post, an interview guide and a scoring rubric.

Priority order and publishing status are in the [priority list](../docs/PRIORITIES.md). The work
queue is in the [to-do project list](../docs/TODO.md).
